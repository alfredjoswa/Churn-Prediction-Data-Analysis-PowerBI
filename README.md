# Customer Churn Prediction and Data Analytics Dashboard

## Project Overview

This project focuses on customer churn analysis using Microsoft Power BI. It provides an interactive dashboard to analyse customer behaviour, monitor key performance indicators (KPIs), and identify patterns associated with customer attrition.

The dashboard transforms customer data into meaningful visual insights to support business decision-making and customer retention strategies.

## Objectives

* Analyse customer churn and retention patterns.
* Monitor key business metrics through interactive visualisations.
* Identify customer segments associated with higher churn.
* Explore customer behaviour and attrition trends.
* Support data-driven decisions to improve customer retention.

## Tools and Technologies

## Getting Started

### Prerequisites

* Microsoft Power BI Desktop
* Access to the dataset used in the project, if required

### Installation and Usage

1. Clone or download this repository.
2. Navigate to the `dashboard` directory.
3. Open `Customer_Churn_Dashboard.pbix` using Microsoft Power BI Desktop.
4. Configure the data source if prompted.
5. Refresh the data if the source is available.
6. Explore the dashboard and its visualisations.

## Business Value

Customer churn analysis helps organisations understand customer attrition and identify areas where retention strategies may be improved.

The dashboard provides a visual overview of customer churn patterns, helping stakeholders explore relevant customer segments and make informed business decisions.
